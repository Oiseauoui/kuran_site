# Уроки Корану — сайт

Легкий сайт: список аудіо-уроків, під кожним — PDF з тафсіром. Аудіо можна
слухати на швидкості 0.5x–1.5x і перемотувати на 10 секунд назад.

## Що всередині

- `index.html`, `style.css`, `script.js` — сам сайт
- `content/lessons.json` — список уроків (керується через адмінку)
- `admin/` — панель для вчителя (Decap CMS)
- `uploads/` — сюди потраплятимуть завантажені аудіо та PDF

## Запуск (один раз, ~10 хвилин)

1. **Створи репозиторій на GitHub** і заливай туди всі ці файли
   (наприклад, через github.com → New repository → залити файли перетягуванням).

2. **Підключи Netlify**
   - Зареєструйся на [netlify.com](https://www.netlify.com) (безкоштовно).
   - "Add new site" → "Import an existing project" → обери свій GitHub-репозиторій.
   - Publish directory: залиш `.` (кореневу), build command не потрібен — Netlify підхопить `netlify.toml`.
   - Натисни Deploy.

3. **Увімкни Identity (вхід для вчителя)**
   - У Netlify: Site configuration → Identity → Enable Identity.
   - Там же: Registration → постав "Invite only" (щоб чужі люди не могли зареєструватись).

4. **Увімкни Git Gateway**
   - Site configuration → Identity → Services → Git Gateway → Enable Git Gateway.
   - Це дозволяє адмінці зберігати файли прямо в репозиторій без окремого сервера.

5. **Запроси вчителя**
   - Site configuration → Identity → Invite users → введи його email.
   - Він отримає лист, встановить пароль і зможе заходити.

6. **Готово** — вчитель заходить на `твій-сайт.netlify.app/admin`,
   натискає "New Lessons", заповнює назву, аудіо, PDF — і за хвилину-дві
   урок з'являється на головній сторінці.

## Важливо про розмір файлів

30-хвилинний mp3 зазвичай важить 20–40 МБ. Netlify Free tier витримує це
без проблем, але якщо уроків назбирається дуже багато (сотні), варто буде
або перейти на платний план Netlify, або зберігати аудіо на окремому
файловому сховищі (наприклад, Cloudinary чи Bunny.net) — про це можна
подумати пізніше, коли контенту стане більше.

## Локальна перевірка

Щоб просто подивитись, як виглядає сайт, не деплоячи його:

```bash
python3 -m http.server 8000
```

і відкрити `http://localhost:8000` — але саму адмінку (`/admin`) так
перевірити не вийде, вона працює лише після підключення Netlify Identity.
